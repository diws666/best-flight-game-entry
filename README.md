# Skydrift — best flight game entry

A procedural 3D flight game for the make.fun "best flight game" bounty. Chase camera behind a small aircraft over recognisable terrain (heightmap hills, a lake, a runway, trees and buildings, clouds, sun). Fly through the chain of glowing target rings for score, then land on the runway. Fuel drains; hitting terrain or running out of fuel crashes; a clean runway landing completes the mission. Title screen, pause, restart, game over and mission-complete screens. HUD shows altitude, speed, heading, fuel, score and ring counter. Keyboard plus optional mouse steering. Static files under game/ only, no network at runtime, three.js vendored under game/vendor/.
